蒸馏工作台节点页面 mock

这是产品化前端节点草图，只表达页面结构、字段、状态和边界；不执行生题、蒸馏、联网、写回或入库。

1. 样本集创建

把真题样本、split、题型元数据和 generation request 登记成可复用 dataset。

可运行输入契约

输出

dataset_idds_...

边界

只登记样本，不蒸馏、不写题卡、不调用模型。

2. 蒸馏会话

围绕一个 dataset 或 baseline request 创建可追踪的实验会话。

3. 试跑

从会话中抽取样本跑 trial，生成 run、fit summary、item preview 和错误快照。

结果

statuscompleted

4. 人工审核

人工判断 run 是否允许进入 promotion，并明确允许的 target。

human gate不可绕过

保护

未审核、未允许 promote 或缺 target 的 run 不能进入 promotion。

5. 补丁登记

把 evidence、draft 或 path 作为 workbench patch 登记，不直接改正式配置。

canonical target只登记

兼容

旧 target 会 normalize 到 canonical target。

6. 候选轴确认

用户把 bootstrap hypothesis 标记为 keep / drop / rename / split / merge，并生成 proto-confirmed。

不是 formaldraft only

输出

axis_confirmationproto_confirmed
formal_patch_draftdraft_only

7. 写回计划预览

把 draft 变成 writeback plan 和 diff 预览，仍然不写文件。

不写回需要审批

审查点

必须包含目标文件、forward patch、rollback patch、回归命令和审批字段。

8. 来源候选人审

用户审查 candidate source，生成 review decisions 与 seed-only 来源种子。

seed only不确认原文

禁止

不抓正文、不入库、不生成 material_card、不设置 verified=true。

9. 证据 promotion

只有 review 允许且每个 target 都有 patch 时，才能生成 promotion bundle。

bundle不自动写回

输出

promotion artifact 保存 run snapshot、review、patches 和 targets。

10. 行为包与调试观察

从生成结果构造 behavior packet，用于复盘失败模式和候选 patch。

packetdiff

查看

展示 normalized view、difficulty fit、candidate patches 和 runtime focus。

11. 难度回归

对目标难度、实际难度、gold feel 做 diff/backtest，不直接调 prompt。

projectionassessmentcalibration

边界

patch candidate 必须经过 review/promotion，不能自动改 prompt 或 validator。
